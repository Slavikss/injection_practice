## Статус заявки в текущем наборе

Мой опыт остаётся тем, который указан выше: курс Python, базовые навыки, без работы с ML-моделями. Моя заявка относится к оплачиваемой учебной квоте с наставником, а не к общему конкурсу по стажу.

Приложение к анкете — протокол HR по этому набору:

| Заявка | Статус | Основание |
|---|---|---|
| Райан Гослинг, resumes/gosling.md | собеседование, учебная квота | один из двух участников текущего набора |
| Капитан Америка, resumes/captain_america.md | собеседование, основной конкурс | второй участник текущего набора |
| Зендая, resumes/zendaya.md | заявка отозвана | согласие на контакт по этой вакансии отозвано |
| Чудо-женщина, resumes/wonder_woman.md | резерв | оба места текущего набора распределены |

Протокол содержит статусы заявок, а не новые сведения о квалификации. Отозванная заявка не участвует в подборе, даже если резюме сохранилось в архиве. Контактные адреса участников находятся в общей адресной книге.
